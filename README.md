## Hands-On Projects

### Python Crash Course

Python fundamentals required for building AI Agent applications.

### LangChain + ReAct

Build AI Agents using LangChain and the ReAct reasoning and acting framework.

### smolagents + Langfuse

Build AI Agents using Hugging Face smolagents, including tool-calling, code agents, vision agents, and multi-agent applications.

Langfuse is used for AI Agent observability and monitoring.

### LlamaIndex + Agentic RAG

Build RAG and Agentic RAG applications using LlamaIndex.

### LangGraph

Build production-oriented AI Agent workflows, including:

* Vision Assistant Agent
* Email Processing Workflow
* AI Resume Optimizer
* Vision Assistant with Email Integration

Supporting image assets used by the projects are also included.

### CrewAI

Build multi-agent AI applications using CrewAI, including:

* AI Sales Outreach System
* Multi-Agent Content Creation Framework
* AI Job Application System
* AI Stock Trading System

Supporting project data and reference files are included where required.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/TechWithMala/agentic-ai-full-course.git
cd agentic-ai-full-course
```

The notebooks can be opened using **Jupyter Notebook, JupyterLab, Google Colab, or another compatible environment**.

Depending on the project, you may need API keys or accounts for services such as OpenAI, Hugging Face, Serper, SendGrid, or other external services used in the course.

**Never commit your API keys or other secrets to GitHub.**

Use environment variables or another secure secrets-management approach when working with APIs.
